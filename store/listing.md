# Chrome ウェブストア 提出メモ

提出先：https://chrome.google.com/webstore/devconsole

## 1. パッケージ

PowerShell で `.\store\pack.ps1` を実行すると `store\dist\hiyori-assist-<版>.zip` ができる。これを「新しいアイテム」から上げる。
（manifest.json の `key` は zip の中だけ外れる。ストア版は新しいIDになる）

## 2. ストアの掲載情報

**名前**（manifest のまま）
ヒヨリ 日程入力アシスト

**概要**（132文字以内。manifest の description がそのまま使われる）
伝助・デイコード・調整さん・ヒヨリの入力画面に、フリカレ／Googleカレンダー／テキストからの取り込みやまとめて入力を追加。Googleの予定やヒヨリの確定日を自分のフリカレに書き込むこともできます。

**説明**
```
伝助・デイコード・調整さん・ヒヨリの出欠入力を手伝う拡張機能です。
フリーカレンダー（フリカレ）やGoogleカレンダーの予定を読んで、入力表に○△×をまとめて入れます。

■ 予定は作者のサーバーに送りません
読み込みも○△×への変換も、すべてあなたのブラウザの中で行います。作者のサーバー（ヒヨリを含む）には送りません。
フリカレに書き込むのは、あなたが内容を確かめて「書き込む」を押したときだけです。予定名を書くかどうかも選べます（初期値は記号だけ）。
コードはすべて公開しています。
https://github.com/matumogura/hiyori-assist

■ 出欠入力の画面（伝助・デイコード・調整さん）
・フリカレから取り込む
・Googleカレンダーから取り込む（5つまで重ねられます。フリカレとも重ねられます）
・テキストから取り込む（「9/15 夜」「9/16 ○」のような行）
・まとめて入力（曜日・空欄の日だけを指定して一括で）
・いつもの一言コメント
・元に戻す
どれも画面のボタンを押した状態にするだけです。各サービスの登録ボタンを押すまで保存されません。

■ 伝助の新規作成画面
・期間と曜日から候補日程を作る（平日と土日祝で時刻を分けられます）
・ヒヨリの日程調整から候補日を写す
・並べ替え・重複の整理、自分のフリカレで埋まっている日を消す

■ ヒヨリ
参加者ページの「取り込む」→「Google」から、Googleカレンダーの予定を全・昼・夜・×にして表に入れます。
Googleカレンダーのアドレスなどの設定は、ヒヨリの「自分の設定」でまとめて登録できます（アドレスはこの拡張機能の中にだけ保存されます）。

■ 自分のフリカレに書き込む（ログインしたフリカレの画面で）
・Googleの予定を「×」「昼×」「夜△」などの記号にして書く。予定名を書くかどうかは選べます（初期値は記号だけ）
・ヒヨリで確定した日に、集まりの名前と時刻を書く。いつもの時間なら時刻を省けます
・書く前に変わる日を一覧で確かめ、押したときだけ書きます。「元に戻す」で戻せます

■ Googleカレンダーについて
Googleカレンダーの「iCal形式の非公開アドレス」を使います。アドレスはこの拡張機能の中にだけ保存し、Google以外には送りません。

■ お問い合わせ
Discord：https://discord.gg/KTBmA3N7tW

※ 伝助・デイコード・調整さん・フリーカレンダー・Googleの公式の拡張機能ではありません。
```

**カテゴリ**：仕事効率化（ワークフローと計画）

**サポートURL**：https://discord.gg/KTBmA3N7tW

## 3. プライバシーへの取り組み（Privacy practices タブ）

**単一用途の説明**
```
日程調整サービス（伝助・デイコード・調整さん・ヒヨリ）の入力画面で、利用者のカレンダー（フリーカレンダー・Googleカレンダー）や入力した文から空き状況を判定し、入力表に出欠の記号を入れる手助けをします。
```

**権限が必要な理由**

storage
```
利用者が登録したフリーカレンダーのURL、Googleカレンダーの非公開アドレス、いつものコメント、記号の入れ分けなどの設定を、このブラウザに保存するために使います。フリーカレンダーへの読み込み回数の上限を守るための回数の記録にも使います。
```

declarativeNetRequestWithHostAccess
```
フリーカレンダーの公開カレンダーを読むとき、この拡張機能自身の通信（tabId -1）に限って Origin ヘッダーを外すために使います。フリーカレンダーの読み込み用の窓口が、拡張機能の Origin が付いた通信を受け付けないためです。対象は https://freecalend.com/open/data への拡張機能自身の通信だけで、利用者が開いているページの通信には一切触れません。
```

ホストの権限
```
https://freecalend.com/open/data … 利用者が指定した公開フリーカレンダーを読み取るため（読み取りのみ）。
https://calendar.google.com/calendar/ical/* … 利用者が登録したGoogleカレンダーの非公開アドレスから予定を読むため、および日本の祝日カレンダーを読むため。
https://macchan.onrender.com/api/sched/* … 伝助の新規作成画面で「ヒヨリから写す」を使ったとき、指定された日程調整の題名と候補日を読むため。
コンテンツスクリプトの対象（densuke.biz、character-sheets.appspot.com/schedule/input、chouseisan.com、macchan.onrender.com/sched）… 入力画面に補助のパネルを表示し、入力表のボタンを押すため。また macchan.onrender.com/sched の「自分の設定」に、この拡張機能の設定欄（Googleカレンダーのアドレスなど）を表示するため。
コンテンツスクリプトの対象（https://freecalend.com/*）… 利用者がログインして開いている自分のフリーカレンダーの画面にパネルを表示し、利用者が「書き込む」を押したときだけ、そのページから利用者自身のカレンダーに予定の記号や確定日を書き込むため。書き込む前に変更点を一覧で見せ、元に戻す機能もあります。
```

リモートコード
```
いいえ。外部のスクリプトは読み込みません。すべてのコードはパッケージに含まれています。
```

**データの使用**（迷うところ。控えめに申告する案）
- 収集するデータ：
  - 「認証情報」… Googleカレンダーの非公開アドレス（予定を読める鍵にあたる）を保存するため

## 4. 更新（v1.1.0）の提出

既存のアイテムの「パッケージ」→「新しいパッケージをアップロード」から `store\dist\hiyori-assist-1.1.0.zip` を上げる。
掲載情報の「説明」と、プライバシーへの取り組みの「ホストの権限」を上の文に差し替える（freecalend.com/* が増えたため審査に時間がかかることがある）。
画像は screenshot-2（文言を「予定は作者のサーバーに送りません」に変更）・screenshot-4（新規）・promo-small・promo-marquee（同じ文言の変更）を上げ直す。

審査の補足欄（任意）
```
v1.1.0 で、利用者がログインして開いている自分のフリーカレンダーのページに書き込む機能を追加しました。
そのため freecalend.com/* をコンテンツスクリプトの対象に加えています。書き込みは、利用者が変更点の一覧を確認して「書き込む」を押したときだけ、そのページの中から利用者自身のカレンダーに対して行います。外部のサーバーには何も送りません。
また、設定画面（options.html）をやめ、ヒヨリのサイトの「自分の設定」の中にこの拡張機能が設定欄を描く形にしました（設定はこれまでどおり chrome.storage.local のみに保存）。
```
