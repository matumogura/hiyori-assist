# ヒヨリ 日程入力アシスト（Chrome拡張）

伝助・デイコード・調整さんの出欠入力画面に、ヒヨリと同じ入力手段を追加します。

- **フリカレから取り込む** … 公開フリカレのURLから予定を読み、○△×を入れる
- **テキストから取り込む** … 「9/15 夜」「9/16 ○」のような行を読み取って入れる
- **まとめて入力** … 曜日・空欄の日だけを指定して ○△× を一括で入れる。「◎を○に」のような記号の置き換えもできる
- **元に戻す** … 直前の取り込み・まとめて入力・置き換えの前の状態に戻す

どれも画面上のボタンを押した状態にするだけで、**伝助の「登録する」を押すまで保存されません。**

## まとめて入力の見た目をヒヨリ本体に合わせた（v0.8.2）

- 曜日は7つを同じ幅で1列に並べ、文字そのものを押して選ぶ。「平日」「土日」は見出しの右に小さく置いた
- 「空欄の日だけに入れる」は押して切り替えるボタンにした（入っているときは淡い色に ✓）
- ○△×・空欄に戻す・長押しで全部消すを、曜日と同じ高さで横いっぱいに並べた。「置き換える」はその下
- パネルの色（文字・背景・枠・押すボタン）をヒヨリ本体の青系に合わせた。○△×などの記号の色は、各サービスに合わせたまま

## 拡張のIDを固定した（v0.8.2）

- 置き場所を `Documents\GitHub\hiyori-assist` に移した。読み込み直しのときは chrome://extensions の「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
- manifest.json に `key` を入れたので、フォルダを動かしてもIDは `henlcnamdggcacdjjojpnekegpnpabbj` のまま変わらず、保存した設定も消えない
- Chromeウェブストアに出すときは `key` を消してから提出する（ストアが自前のIDを付ける）

## パネルの置き場所の修正（v0.8.1）

- 参加者が多い伝助で、パネルが表の上に出てしまっていたのを、表の右に戻しました
  - 原因：参加者が多いと、表を包む箱（#regdiv）が画面の幅いっぱいに広がる。箱の右端で余白を測っていたため「右に置く場所が無い」と判断していた
  - 対処：箱の中の表の右端で測るようにした。箱が表より狭く横スクロールしているときは、箱の右端を使う

## 予定の時刻つきテキスト（v0.8.0）

Googleカレンダー ○×テキスト（GAS）が、日ごとの行の後ろに埋まっている時刻を出すようになった。

```
昼 13-18時 / 夜 19-24時　○空き ×不可 △要確認　｜のあとは埋まっている時刻（×予定 △仮）
2026/09/17(木) 昼× 夜△ ｜×10:00-12:00 △19:30-21:00
2026/09/18(金) 昼○ 夜○ ｜なし
2026/10/06(火) 昼× 夜× ｜×終日
```

- 候補に時刻がある（「19:00〜」「19:00〜22:30」）とき、「｜」のあとの時刻と重なるかで判定する。予定と重なれば×、仮の予定だけと重なれば△、どちらとも重ならなければ全日○の区分
- 終わりの時刻が書かれていない候補は、設定「終わりの時刻が書かれていない候補」で決める（開始から2・3・4時間／時間帯の終わりまで。初期値は3時間）。表に時刻付きの候補があるときだけ出る
- 見出しの「昼 13-18時 / 夜 19-24時」も読み、候補の時刻をその区切りで昼・夜に振り分ける（ふだんの都合の当てはめ・「｜」の無い行の判定に使う）
- 「｜」の無い行（古い形式・フリカレ）は、これまでどおり昼・夜の記号で判定する


- 候補名（伝助・デイコード・調整さんの表の日程の名前）に「19:00〜」「昼」「夜」などがあると、その時間帯だけを見て入れる。17時以降は夜、それより前は昼
  - 取り込み元（フリカレ・テキスト）には関係なく、日程サービス側の候補名で決まる
- 設定の説明は、表に時間付きの候補があるときだけ出す
- 「オンなら…」の補足と「（このページと記号の組み合わせごとに保存）」を削除

## 読みやすさ（v0.7.1）

- 文字をひと回り大きく（本文 13→14.5px、小さい字 11〜12px → 12.5〜13.5px）。パネル幅も最大 540px に
- 説明の文を減らした（URLの保存先の注記、まとめて入力の注記、設定の要約、ふだんの都合の補足）

## 調整さん対応・いつものコメント（v0.7.0）

- 調整さん（`chouseisan.com/s?h=…`）に対応。入力欄は「出欠を入力する」や名前のリンクを押したときに下に作られるので、
  出てきたらパネルを出し、消えたら片付け、別の人の入力に切り替わったら作り直す
- 調整さんには記号の設定が無く、最初から全部×（未入力の状態が無い）。そのため「空欄の日だけ」「入力済みの日はそのまま」「空欄に戻す」は出さず、長押しは「全部×に」
- 札の押し方は調整さん自身の処理に任せる（値は 1=○ 2=△ 3=×）
- 設定に「いつもの一言コメント」を追加。コメント欄が空なら、ページ（調整さんは入力欄）を開いたときに自動で入れる。書いてあるコメントは消さない。「入れる」で今すぐ上書きもできる
  - 入れる先: 伝助 `membercomment`／デイコード `#comment`／調整さん `hitokoto`
- 拡張機能のフォルダ名を `hiyori-assist` に変更

## 対応サービス（v0.6.0）

| サービス | 開くページ | 登録ボタン |
|---|---|---|
| 伝助 | 名前を押した入力画面／新規追加の画面 | 登録する |
| デイコード | 個人日程入力ページ（`/schedule/input?key=…&userId=…`） | 日程登録 |
| 調整さん | イベントページで「出欠を入力する」または名前を押したとき | 入力する |

- サービスごとの違い（候補の読み方・記号の読み方・押し方・パネルの置き場所）は `content.js` 冒頭の `SITES` にまとめてある
- デイコードは記号のテンプレート（○△ / ◎○△ / ○ / ○①②③ / 全昼夜 / 自由入力）を作成者が変えられる。
  記号は文字ではなく札の色（BEST / OK / CONDITIONALLY / CONDITIONALLY_PLUS / NG）で値を決め、画面に出ている文字をそのまま入れ分けに使う
- デイコードでは札のクリックをデイコード自身の処理に任せるので、「移動するとデータは保存されません」の警告もいつもどおり出る
- 入れ分けは「サービス・ページ・記号の組み合わせ」ごとに保存。テンプレートが変わったら、その組み合わせで最後に使った入れ分け（無ければ初期値）になる
- 入れ分けの初期値
  - 全昼夜: 全日○→全 昼だけ○→昼 夜だけ○→夜 △→入れない 昼か夜×→入れない 全日×→×
  - ◎○△: 伝助の ◎○△× と同じ
  - ○△ や ○: 全日○→○ 昼だけ・夜だけ→△（無ければ○） △→△ 昼か夜×→△（無ければ×） 全日×→×
  - 読めない記号だけ（①②③ など）: 並び順で先頭を全日、2番目を昼だけ・夜だけに

## 画面（v0.4.0）

[emilkowalski/skills](https://github.com/emilkowalski/skills) の考え方を参考に整理しました。

- よく使う操作を上に、たまにしか触らない「判定の設定」（ふだんの都合・記号の入れ分け）は折りたたみに
- フリカレ／テキストは切り替えタブにして、パネルの縦の長さを抑えた
- 上部に表の集計（◎○△×・空欄の件数）。伝助の表を手で押しても数え直す
- 結果はパネル下のトーストで表示し、その場で「元に戻す」を押せる
- 曜日はボタン式にし、「平日」「土日」をワンタッチで選べる
- 「全部消す」は長押し（1.2秒）。取り消しもできるので確認ダイアログは出さない
- 押した瞬間に少し縮む（scale 0.97 / 160ms）、動きは transform と opacity のみ・300ms 以内、ホバーの変化はマウス環境のみ、動きを減らす設定では移動のアニメーションを止める

## 入れ方（開発者モード）

1. zip を展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選ぶ
4. 伝助の出欠入力画面（名前をクリックした画面／新規追加の画面）を開くと、入力表の右にパネルが出ます
   （画面の幅が足りないときは表の上。右に出たパネルはスクロールしても付いてきます）

更新したときは `chrome://extensions` でこの拡張機能の再読み込みボタンを押してから、伝助のページを開き直してください。

## 判定のしかた

- 判定ロジックはヒヨリ本体の `app/sched/availability.mjs` をそのまま移植（`availability.js`）
- 判定結果を6つの区分に分け、区分ごとにどの記号を入れるかをパネルの「記号の入れ分け」で選べる
  - 全日○ ／ 昼だけ○ ／ 夜だけ○ ／ △（不明・△と書いた） ／ 昼か夜×（片方×・片方不明） ／ 全日×
  - 「入れない」を選ぶと、その区分の日は触らない
  - 初期値（◎○△×の伝助）: 全日○→◎ 昼だけ○→○ 夜だけ○→○ △→△ 昼か夜×→△ 全日×→×
  - 初期値（○△×の伝助）: 全日○→○ 昼だけ○→△ 夜だけ○→△ △→△ 昼か夜×→△ 全日×→×
  - 伝助のページごとに保存。初めて開くページには、同じ記号の組み合わせで最後に使った入れ分けを使う
- 「ふだんの都合で昼の予定を上書き」（初期値オン）: ふだんの都合を上限として重ねる。例：「平日の昼は仕事」なら、平日の「昼○ 夜○」は「昼× 夜○」＝夜だけ○として入れる
- 候補名に「昼」「夜」「19:00」などが書いてあれば、その時間帯だけで判定
- 年の無い候補日（9/15 など）は、ページ下の「作成日時」を基準に年を補う
- 祝日は Google の公開カレンダーから取得（取れなければ土日のみ）

## フリカレ取得のマナー

- 「取り込む」を押したときだけ取得。定期取得はしない
- 同じ月は30分キャッシュ、1カレンダーあたり1日10回まで
- 読み取り専用。フリカレのURLはこのブラウザの中にだけ保存
